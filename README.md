# Youtube
A static YouTube clone developed using HTML and CSS. It recreates the YouTube homepage layout including the header, sidebar, and video grid. With a primary emphasis on layout structuring and interface design, the overall structure is built using div-based components, focusing on visual accuracy and consistency across the interface. Flexbox, including nested Flexbox layouts, is extensively used to manage alignment, spacing, and content flow, while CSS Grid is applied to structure the video content section. CSS positioning techniques are used to organize fixed and aligned elements such as the header and sidebar. Together, these approaches demonstrate practical application of modern CSS layout methods commonly used in real-world web interfaces.
