# Youtube
A static YouTube clone developed using HTML and CSS. It recreates the YouTube homepage layout including the header, sidebar, and video grid. With a primary emphasis on layout structuring and interface design, the overall structure is built using div-based components, focusing on visual accuracy and consistency across the interface. The implementation makes effective use of core CSS layout techniques. Flexbox is used to handle alignment and content distribution within major sections such as the header and sidebar, while CSS Grid is applied to structure the video content area in a clean and scalable manner. CSS positioning techniques are used to manage fixed and aligned elements, contributing to a stable and responsive layout. Overall, the project demonstrates a strong understanding of fundamental frontend styling and layout principles commonly applied in modern web development.
